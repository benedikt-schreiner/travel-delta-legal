# Assistance

Vous avez une question, avez trouvé un bug ou avez besoin d'aide avec Travel Delta ? Nous sommes là pour vous aider.

## Contact

E-mail : [benedikt.schreiner@googlemail.com](mailto:benedikt.schreiner@googlemail.com)

Nous nous efforçons de répondre aux demandes sous quelques jours ouvrés.

## Sujets fréquents

**La fonctionnalité Premium ne se débloque pas après l'achat**
Vérifiez d'abord dans les paramètres de l'application, sous « Restaurer les achats », si la fonctionnalité Premium peut être débloquée à nouveau. Si le problème persiste, contactez-nous par e-mail en indiquant la date d'achat et, si possible, le reçu de l'App Store ou de Google Play.

**Informations de voyage incorrectes ou obsolètes**
Les conditions d'entrée, le code de la route et les autres données de voyage peuvent changer à court terme. Si vous constatez une erreur, n'hésitez pas à nous le signaler par e-mail.

**Bugs ou plantages**
Merci de décrire aussi précisément que possible ce que vous faisiez lorsque le problème est survenu, ainsi que le modèle de votre appareil et la version de l'application (indiquée dans les paramètres).
