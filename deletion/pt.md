# Pedido de eliminação de dados

Esta página explica como pode solicitar a eliminação dos dados associados à aplicação **Travel Delta**, publicada por Benedikt Schreiner.

## 1. Dados armazenados apenas no seu dispositivo

A maioria dos dados da aplicação (países selecionados, rotas guardadas, preferências, dados de viagem em cache) é armazenada exclusivamente no seu dispositivo. Estes dados são **eliminados automática e permanentemente assim que desinstala a aplicação** — não é necessário nenhum pedido.

## 2. Dados armazenados no nosso servidor

O único dado que sai do seu dispositivo é um identificador de dispositivo anónimo gerado aleatoriamente, utilizado exclusivamente para atribuir códigos de convite (funcionalidade "convidar um amigo"). Este identificador é armazenado no nosso backend (Supabase). Não está associado a nenhum nome, endereço de e-mail ou outro dado pessoal.

## 3. Como solicitar a eliminação

**Na aplicação (recomendado):** Abra **Definições → Sobre → Eliminar os meus dados**. Isto elimina imediata e permanentemente o identificador do servidor descrito acima, sem período de espera.

**Por e-mail (se já não tiver a aplicação instalada):** Envie um e-mail para **support@schreiner-apps.de** com o assunto "Data Deletion Request", indicando o seu identificador de dispositivo, caso ainda o tenha. Iremos localizar e eliminar o registo associado; receberá uma confirmação dentro de **30 dias**.

Podemos reter informações mínimas por um curto período após a eliminação (por exemplo, para prevenir abusos do sistema de convites), mas nunca mais de 30 dias após o seu pedido, salvo obrigação legal de retenção mais longa.

**Se já desinstalou a aplicação sem anotar o seu identificador de dispositivo:** Uma vez que este identificador nunca esteve associado ao seu nome, endereço de e-mail ou outros dados pessoais, não temos forma de determinar qual registo era o seu. Nesse caso, não é possível uma eliminação manual específica — mas não se preocupe: estes dados são eliminados automática e permanentemente no prazo máximo de **180 dias** após a sua criação, independentemente de ser feito um pedido.

## 4. Dados que não retemos

Não utilizamos SDKs de análise, rastreamento ou publicidade. Por isso, não existe qualquer perfil de utilização ou dados comportamentais além do que foi descrito acima.

Para mais detalhes, consulte a nossa [Política de Privacidade](../privacy/pt.html).
